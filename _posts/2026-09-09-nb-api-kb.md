NocoBase 的知识库（Knowledge Base）配合 AI 员工做 RAG 检索。`nb api kb` 提供了创建、命中测试等命令，我实测时先被交互式提示逐个字段追问了一遍，最后还吃了一个「Unsupported knowledge base type」的闭门羹。这篇把完整过程和原因记下来。

## 命令用途

- `list` / `get` / `create` / `destroy`：知识库的生命周期管理
- `run-hit-test`：对已有知识库跑一次检索命中测试（验证切片与召回效果）
- `list-external-vector-store-providers`：列出可用的外部向量库 provider

## 语法与常用参数

```bash
nb api kb list

nb api kb create \
  --knowledge-base-type local \
  --key demo-kb \
  --name "演示知识库" \
  --enabled true

nb api kb run-hit-test --filter-by-tk <kbKey> --values '{"query":"..."}'

nb api kb list-external-vector-store-providers
```

## 实测效果

直接敲 `create` 不带参数，CLI 不会一次性列出所有缺的字段，而是**一个一个报**：

```bash
$ nb api kb create
# error: required option --knowledge-base-type <value>

$ nb api kb create --knowledge-base-type local
# error: required option --key <value>

$ nb api kb create --knowledge-base-type local --key demo-kb
# error: required option --name <value>

$ nb api kb create --knowledge-base-type local --key demo-kb --name "演示知识库"
# error: required option --enabled <value>
```

四个必填项全补齐后，我以为能过了，结果：

```bash
$ nb api kb create --knowledge-base-type local --key demo-kb \
    --name "演示知识库" --enabled true
# Unsupported knowledge base type: local.
```

不是参数错了，是**这个实例不支持 local 类型**。

## 踩坑点

**1. 逐字段报错的交互很磨人。** 与其一次次试错，不如先 `nb api kb create --help` 把必填项一次看全。这个模式在其它 `nb api` 子命令上也存在，写脚本时务必先查 help。

**2. `Unsupported knowledge base type: local` 的真实原因。** 不是命令或参数问题，而是**实例没有启用本地向量库插件**——知识库功能依赖向量库，远程共享 demo 实例上通常只装了外部向量库支持，没开本地那份。判断办法：执行 `nb api kb list-external-vector-store-providers`，如果只有外部 provider 可选，就说明 local 这条路在这个实例上是关的。解法要么在插件管理器里启用本地向量库（需要有权限），要么配置一个外部向量库再用非 local 类型建库。

**3. `list` 返回空数组不一定是坏事。** 实例上还没建过知识库时 `list` 就是 `[]`，别和「功能不可用」混淆——区别在于 create 会不会报 Unsupported。

**4. run-hit-test 只对已建成且有内容的库有意义。** 建库失败/为空时跑它只会得到空结果，先确认文档已经入库。

## 什么时候用

- 给 AI 员工配知识库前，先用 `run-hit-test` 验证召回质量，再绑定到员工
- 排查「AI 员工答不出领域问题」时，先确认它挂的知识库命中测试是否正常
- 多环境部署时用 `list-external-vector-store-providers` 提前确认向量库依赖

顺带一句：这次实测让我养成了习惯——在共享/托管实例上动 `nb api` 之前，先用只读命令（list / get / providers）探一下能力边界，别等到 create 报错才知道功能没开。
